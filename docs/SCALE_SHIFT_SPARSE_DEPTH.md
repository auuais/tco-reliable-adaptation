# Scale-and-shift sparse-depth development test

Use only the original three development scenes and both sealed neighboring-depth grids. The previous held-out results are observed evidence for the earlier method. No held-out or TUM labels enter fitting or hyperparameter selection.

Start with the scene-median measured-to-predicted log-depth gauge g. In metric units fit y = a(gd) + b to the sparse measured axial depths. Normalize both axes by median measured depth. Fit one scene-wide affine map and one map per target view. Use five fixed Huber reweighting iterations with normalized residual transition 0.02. Add a quadratic prior centered at a = 1 and normalized b = 0 with weight 0.01 times the observation count on each coefficient. Bound a to [0.5,2] and normalized b to [-0.25,0.25] using constrained least squares. Floor every calibrated prediction at one quarter of its gauge-scaled initial depth, shared by all calibrated arms, and report the floored fraction.

Compare scene affine calibration alone, per-view affine calibration alone, and per-view affine calibration followed by the frozen local-constant depth-aware correction. The last is the primary candidate. The earlier pixel bandwidth, depth bandwidth, log residual bound and eight-neighbor selection remain fixed. Re-estimate the common scene gauge from each calibrated depth set using the same scene-median rule. The per-view calibration-alone arm and its locally corrected candidate share that gauge. All arms use the same supplied cameras and sparse inputs.

Seal eighteen five-view outputs before scoring. Include every earlier comparator, including the original depth-aware update and both affine controls. Keep the existing 5 percent aggregate gain, historical comparison, 2 percent component safety, no-scene-regression and released-reference checks for both grids. This is a classical calibration baseline with a fixed residual update. Treat any benefit as an experimental result and compare existing sparse-depth completion methods before a publication claim.
