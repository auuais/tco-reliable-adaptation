# Can a local depth correction transfer to pixels with no proposal?

The natural-depth input study found that pixels jointly eligible in all four camera/source conditions covered 22.40% of valid pixels but only 5.98% of the axial error removable by the candidate grid. Test the hypothesis that low-frequency depth bias can be estimated in one part of an image and applied elsewhere. Use only the existing development images. The test is local and spends no cloud budget.

For each image divide the raster into alternating 16×16-pixel blocks. Fit on one block color and evaluate on the other, then reverse and pool the two directions so every evaluated pixel was spatially excluded from its fit. The primary evaluation pixels have valid reference depth and no nonidentity first-source proposal in the visibility study. Report the fraction of the valid image they cover. Keep the camera, focal lengths and direct-focal global similarity fixed. Run both references separately.

Divide each image into 1×1, 2×2, 4×4 and 8×8 equal-sized rectangular tiles in normalized raster coordinates. Fit one continuous axial-depth multiplier per tile, bounded between exp(−0.08) and exp(+0.08), using at least 16 samples. Use identity in unsupported tiles. For an aligned frozen point p and displacement b from its aligned camera center, the corrected point is p + λb. Least squares gives λ equal to the sum of b·(g−p) divided by the sum of squared ray lengths, with the stated bounds on 1+λ.

Compare four sources of training targets. First use reference geometry at every valid training pixel. Second use reference geometry only at valid sites where the first source proposed a nonzero change. Third draw the same number of training sites at random among all valid training pixels **within each tile** and use reference geometry there. Derive the random seed deterministically from the batch, view, grid and block color and reuse the selection on both references. Fourth use the first source's actual proposed depth at its proposed training sites. This fourth estimator uses the frozen ray lengths, all proposal sites on the training block color and no reference masks to choose its multiplier. An isotropic global alignment scales all ray weights equally. These are controlled estimates of spatial predictability, not an independent dataset or an advancement test.

Report the condition-normalized reduction in corresponding-pixel squared error, changed area on the primary evaluation pixels and scene breakdowns. Use 4×4 as the main comparison and publish all resolutions. Fixed tiles isolate how much a transferable spatial bias exists before introducing learned boundaries or an external depth model. If exact depth at proposal sites fails to transfer, increasing the sophistication of those weights alone has little empirical motivation under this tiling. These results do not replace dense surface scoring of a future deployable method.
