# Joint camera and depth updates from RGB reprojection

Use the original offset-25 development images, the archived median-depth and camera ensemble, direct-focal intrinsics, and the original seed-137 supplied poses. Fit corrections using the existing feature-disjoint RGB match folds. For each matched pixel, lift its model depth into 3D, transform into the paired view and penalize the difference between its projected pixel and the measured match. Include both projection directions. The reference surfaces are unavailable to fitting and acceptance.

Keep the first camera fixed. Fit other camera rotations and centers in the initial world frame, bounding rotation-vector components at 2 degrees and center components at 0.02 median depth. Each view can adjust log depth using an intercept and a slope on clipped normalized disparity, each bounded at 0.04. Use the median initial depth as the common scale. Anchor the first view's depth intercept at zero. Use a soft-L1 reprojection loss with scale 3 pixels and zero-centered parameter regularization: one unit of normalized squared parameter cost at 1 degree, 1% median depth, or 0.02 log depth, with total regularization averaged over available parameters and reprojection costs averaged over observed components. For the primary joint-with-prior arm, add an equally weighted regularizer to the aligned supplied camera target using the same camera units; fix its global gauge to camera zero. Compare pose-only, depth-only and joint without a prior, all with the same RGB observations, optimization budget and guards. Use a connected five-view training graph and require a 1% decline of the robust reprojection loss on the disjoint validation fold to accept a proposed correction. Otherwise emit the initial joint model. Evaluate every sealed scene against both canonical references. Do not tune on held-out scenes or release funds on the basis of improving reprojection alone.
