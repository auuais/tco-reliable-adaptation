# Which frozen camera components displace a true correspondence?

Use the existing 15 target cameras, their four short-spacing neighbors and sealed RGB motion fields. Measure reprojection at known target depth to characterize the frozen rig after the previously fixed local-to-metric depth conversion. This is an offline camera diagnostic. It does not advance the cloud plan.

Work in each target camera's coordinate system. Separate five components of the relative rig: intrinsics (focal and principal point at both endpoints), relative rotation, translation direction, the geometric mean of the four target-to-source distances, and the four distances divided by that mean. Cross the frozen and measured values of all five components to obtain 32 configurations. Include the full frozen and measured endpoints and every single substitution. The source centers and rotations define target-to-source reprojection directly.

Use pixels on the fixed stride-eight grid starting at (4,4). Apply the same measured visibility and DIS cycle masks as in the paired correspondence control. For each source use fixed common support across all configurations, requiring positive finite projected depth in each. Additionally require at least one pixel of ideal image displacement per log-depth unit, measured by the analytic derivative of the reference projection. Report the resulting support per edge and all aggregate denominators. Verify the derivative by central differences and the two endpoint projections against the original reference and frozen world-coordinate rigs.

Measure squared two-dimensional reprojection error at true depth. Also project the error onto the reference depth derivative and divide by its magnitude to estimate squared log-depth displacement to first order. This is a local sensitivity diagnostic, not a measured reconstruction error. Average pixels within an edge, edges within a target, then targets within a scene and across scenes. Explain the change from all-frozen to all-measured by averaging each component's marginal error reduction over the 120 substitution orders (Shapley attribution). Report signs, percentage shares and individual full-frozen single substitutions. Negative shares can occur when estimated errors cancel. Report aggregate and each scene, and identify whether the dominant geometry component is consistent across scenes. No parameter is fitted on target depth.
