# Locate the surface error before and after ICP

Use the registered and released references, exact original valid pixels, direct-focal and weighted reconstructions for all three scenes. Apply the upstream Umeyama transformation independently to each arm. Measure mean predicted-to-reference and reference-to-predicted nearest-neighbor distances before ICP. Then report these distances on the same predictions after the direct-focal rigid ICP transform and after each arm's own upstream rigid ICP. Reproduce both archived final accuracy and completeness values for each scene and reference; report differences or fail the comparison if the maximum discrepancy exceeds 0.00002 metres. Also record ICP fitness, inlier RMSE, rotations and translations. Compare matched scene-normalized scores against direct focal. These diagnostics distinguish changing correspondence and changing alignment from the measured corresponding-pixel result. They are development evidence and do not release transfer spending.
