# Joint rotation and translation-direction control

Use the same 15 targets, short-spacing RGB motion pairs, fixed model baseline lengths and depth gauges as the external orientation study. Compare the archived frozen and orientation-only controls with (1) an exact direction aid with frozen rotations, (2) exact directions and rotations, and (3) jointly perturbed directions and rotations. The primary condition uses the previous three seeds and one degree per absolute orientation, plus five degrees per baseline direction in the target camera frame. Direction noise acts along a random unit tangent at the true direction, with independent deterministic draws per edge and seed. Preserve target camera, focal calibration and original target depth. Use the any-source median and quarter-strength bounded update. Score all valid natural target pixels. Compare paired error against unchanged depth, frozen cameras, and orientation-only under the same seed. Consider local surface scoring only for at least 2% aggregate reduction against frozen cameras, with improvements against all three controls in each scene. These simulated inputs test feasibility on development scenes. Cloud budget is zero.
