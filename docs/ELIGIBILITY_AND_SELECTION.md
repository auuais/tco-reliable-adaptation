# Where does bias enter when sparse depth corrections are propagated?

The previous spatial study fitted a scale in each of sixteen tiles per view. Giving it reference depth only where the first source asked for a change increased squared error on withheld pixels without proposals by 10.60%. Location-matched counts sampled randomly across the same tiles reduced that error by 8.07%. This test separates availability of an observation from the later decision to discard zero updates. It uses the same previous development images, 4×4 tiles, alternating 16×16 spatial block colors, fixed direct-focal alignment, minimum 16 fitting observations, bounded scale and two depth references. No new GPU rental or dataset access is required.

Replay the sealed frozen estimator and record the first-source eligibility mask for every pixel. Match its previously published eligibility count and reproduce all five original correction-index maps exactly. Partition the raster into first-source nonzero proposal, eligible with an identity proposal, and unavailable. The primary test set comprises withheld valid pixels in the latter two groups. Report these two groups separately as well as combined. Source availability and the proposed value must be obtained without reference geometry. Any reference-based training arm below is a labeled diagnostic.

Within each spatial training block color and tile, repeat the reference-assisted fit at all eligible pixels, only the nonzero proposals, and only the eligible identity proposals. In two matched-count controls, draw as many valid eligible sites as there are valid nonzero proposals, and draw as many valid training pixels anywhere as there are valid eligible sites. Use deterministic sampling without replacement. Also retain the prior matched-count random reference control at the proposal count. Compare the nonzero-proposal fit against the equally sized draw from eligible sites to test selection by disagreement. Compare the all-eligible fit against its equally sized draw from all valid training sites to test selection by visibility.

Test deployable estimates learned from the actual source corrections under three rules. Fit to nonzero proposals, fit to all eligible observations including identity, and fit to all eligible observations within three frozen-depth bands inside each tile. Determine the two band boundaries from the 1/3 and 2/3 quantiles of frozen axial depth in the full tile, independently of training labels and reference masks. Use the same least-squares ray weighting, scale bounds and minimum support as before. A band with inadequate observations keeps identity. Fit and score the two block directions separately and combine their withheld squared errors. Report changed fraction, both references, and all three scenes. A gain on this diagnostic merits a new registered dense comparison. It cannot release the separate MASt3R allocation by itself.
