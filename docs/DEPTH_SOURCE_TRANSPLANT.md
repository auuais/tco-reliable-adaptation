# Which input explains the gap between controlled and natural depth corrections?

The positive control recovered the exact depth on about 87–89% of eligible pixels with an injected log-depth error of ±0.08. On natural frozen outputs, 43.39% of accepted changes reduced registered 3D error. The proposed diagnostic crosses the camera rig, source depths and target starting depth while holding the images and decision rule fixed.

Use the same nine development RGB batches and existing reference camera fits. Keep one meter scale per batch, equal to the median of reference axial depth divided by frozen axial depth over all valid pixels in all five views. Multiply frozen axial depths and frozen camera translations by this scale. The scale uses reference information and cannot enter the deployed method. The frozen rig uses the same selected focal lengths and frozen principal points as the model experiment. Projection uses relative poses inside each rig, so no alignment of world axes is required. The camera factor includes differences in the relative translations, rotations and intrinsics.

Cross reference versus scaled frozen camera rigs with reference versus scaled frozen source depths. Reference and frozen source maps use the same valid reference mask, including NaNs outside it. For each target use the reference axial depth with log offsets −0.08, 0 and +0.08, and independently use the natural scaled frozen target depth. In all sixteen cells use the registered starting-depth visibility, five candidate factors, depth discrepancy, 5×5 patch and two nearest eligible source views. Keep the 5% reduction check on each source. The reference-camera/reference-source injected controls must reproduce the prior eligible and choice histograms. Verify that scaling both translations and depths in a rig leaves the projected geometry and decisions unchanged in a synthetic example.

For injected depths report eligibility, exact recovery on all valid pixels and conditional exact recovery. For natural inputs report mean squared log-depth error before and after, the fraction modified, the fraction improved among changes and the attainable result of choosing the best available discrete depth at each pixel. Also report on pixels eligible in all four rig/source settings, so changes in coverage can be distinguished from changes in estimation. Average the twelve development conditions equally and provide scene-level results. This diagnostic uses reference geometry to separate mechanisms. It cannot release a later budget allocation.
