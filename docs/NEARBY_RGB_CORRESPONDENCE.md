# Can RGB correspondences supply an independent depth measurement?

On the fifteen short-spacing targets, replacing predicted source depths with measured depths made the two-source update useful even with frozen cameras. Test whether RGB motion supplies a usable replacement for the depth cue. This is a local feasibility experiment for a redesigned estimator. It uses the existing images and frozen captures. It has no cloud allocation.

1. For each target and each of its four short-spacing sources, run OpenCV DIS at its medium preset, once in each direction, on the original grayscale images. A flow is accepted only if the bilinear return flow lands within one pixel of the starting point. Compute all correspondences without image depth, projected initialization, dataset poses or target labels. Record OpenCV version, flags and processing time. Freeze the flow fields before scoring.
2. At every target pixel, triangulate its bearing against the matched source bearing. Use the existing point-to-ray least-squares formula in the local camera gauge, require positive depth in both cameras, at least one degree between the rays and a source reprojection error at most one pixel. Take the median in log depth across the available sources. The primary rule requires a valid source from before the target and one after it, with at most 0.08 difference between the medians of the two sides in log depth. Include a simpler baseline accepting a single valid source or more. Count eligible pixels per target. Use all four available sources for each estimate.
3. Evaluate both measured and frozen camera rigs using the sealed flows, keeping the same focal calibration and depth-unit conversion as the previous nearby camera/depth diagnostic. The measured-camera arm diagnoses flow quality and triangulation. The frozen-camera arm tests feasibility under deployable inputs. No reference source depth or source validity mask enters either inference arm. Target truth masks only determine reporting. Run a noiseless synthetic plane with known calibration to test sign, reprojection and gauge before running the data.
4. Preserve each original target depth wherever the rule abstains. At eligible pixels apply the log-depth correction indicated by triangulation, bounded to ±0.08 around the starting depth. Use the same starting states as the previous study. The two-sided frozen-camera result on the natural target is primary. Report the paired change in squared log-depth error by target and scene, clean-target error introduced, recovery of injected log-depth errors, support and fraction of actual edits closer to truth. Separate the error on all valid pixels from the error on the pixels each rule can observe.
5. Proceed to a separately registered whole-surface redesign only if the primary reduces natural depth error on all three scenes, improves aggregate natural error and reduces natural error more than the simpler rule on average. Any such result still needs the independent full surface threshold against the best same-input controls before transfer spending. These development targets have already been used for diagnostics and cannot support a generalization claim.
