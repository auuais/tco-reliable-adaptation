# Does a relative-orientation aid improve natural target depth?

Relative rotation dominated depth-sensitive reprojection error in the nearby-rig component study. Test the effect on actual target predictions using an idealized orientation aid, without changing frozen translation, intrinsic calibration, original target poses or the 60 RGB motion pairs. Use the same 15 short-spacing development targets. The data do not include an IMU stream.

## Inputs and predeclared settings

Use the original DIS correspondences, one-pixel cycle test and one-degree minimum triangulation angle. Do not use measured depth or source validity to choose matches, eligible pixels, gauges or weights. Preserve the frozen cameras' centers expressed in the frozen target camera frame, in the same units as the frozen depths. Compare the frozen relative rotations to exact dataset-derived relative rotations. For each of three fixed seeds (11, 29, 47), perturb each physical frame's absolute camera orientation with a fixed-angle rotation around an independent uniformly sampled unit axis in its camera frame. Use 0.25°, 1° and 3° absolute orientation error. Share the axis for a frame between noise magnitudes. Obtain the noisy relative rotation by composing the perturbed source and target orientations. A common change of world coordinates must leave all relative rotations unchanged.

Use the any-source median log-depth estimate as primary because the previous step-size study favored it. Apply one quarter of the triangulation correction after clipping the suggested log-depth displacement to ±0.08. Declare this fixed weight as development-informed. Include the original frozen-camera rule with the same weight, the unchanged dispersed depth, the earlier two-sided support rule and the full correction for both forms of support. The exact and noisy rotations are diagnostic inputs. Record their actual relative angular error by pair and seed. Verify that the frozen relative representation preserves existing triangulations and both archived unit-step errors, within floating-point tolerance.

## Scores and decision

Evaluate actual natural target depths after sealing predictions as in the neighboring motion study, using the original frozen-to-metric gauge. Score mean per-target reduction in squared log-depth error versus unchanged depth, plus paired gain against the same-weight frozen-camera rule. Report all development scenes, both support rules, all noise levels and seed variation. The primary controlled input is 1° per absolute orientation. Average the seeds within each target before averaging targets. Report the exact-orientation ceiling and both other magnitudes as sensitivities.

Only consider a later, separately specified local surface test for this changed method if the 1° primary beats unchanged and same-weight frozen cameras on each of the three scenes and by at least 2% relative squared-depth error against the latter overall. Measure exact candidate and baseline errors on identical valid target pixels. A successful offline aid still requires real sensor data, extrinsic and timing calibration, matched deployable baselines, the existing 5% surface criterion, and an independent scene split before any performance or publication claim. This diagnostic costs $0 in cloud compute and releases no later funds.
