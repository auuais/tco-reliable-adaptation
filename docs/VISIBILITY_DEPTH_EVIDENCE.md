# Separating visibility, source-view support and depth evidence

With reference cameras and short versus long injected depths, the prior four-view RGB check admitted 3.39% versus 0.35% of valid pixels. It also changed 30.4% of eligible clean pixels. These results motivate a local factorial experiment. The source images, five depth hypotheses, neighborhood size, error magnitude, camera convention and nine unique development RGB batches remain those in the published positive control.

Cross three design choices. First compare requiring **every candidate** to pass the source-depth occlusion test against requiring the **starting depth** to pass it. In the latter rule every candidate must still project inside the valid observable footprint. A candidate that projects behind the sampled source depth by more than 10% receives the maximum local cost of 0.2. Its cost remains in the patch average. This makes the denominator the same for all candidates and lets the other candidates compete.

Second compare the original high-pass RGB discrepancy against `0.2 * min(abs(log(z_projected / z_source)) / log(1.10), 1)`. The latter measures source-depth agreement in camera coordinates. Third compare the existing four-view fitting/validation split to a two-witness rule. At each pixel take the two nearest eligible source views in the original baseline order. The nearest proposes the minimum-cost candidate and the next must confirm it. Both source costs must decrease by at least 5% from a baseline above 1e-6. A single-source control takes the first eligible view's best candidate, with identity on ties. Source selection uses eligibility and baseline distance alone. Report single-source results to distinguish improved observations from simply abstaining.

First run all factors on reference cameras and source-depth maps under the known ±0.08 log-depth errors and clean starting condition. The previous all-candidate RGB four-view decisions must reproduce exactly. Report eligibility, exact recovery over all pixels, recovery conditional on eligibility, improvements among edits and clean false edits. Report both signs and every scene. These controls explain mechanisms and use privileged information.

Then test the fixed primary estimator with frozen model poses and source depths, starting-focal calibration, starting-depth visibility, depth discrepancy and two witnesses. Use the same local simple controls as the dense RGB experiment and add single-source depth, two-witness RGB with starting-depth visibility, four-view depth with starting-depth visibility and two-witness depth with all-candidate visibility. Retain the prior dense RGB controls. Use current public inputs and both depth references, with all inferences sealed before evaluation. Keep the same 5% registered surface criterion, 2% component limits, scene guard, secondary-reference safeguard and historical comparison. Publish pixel-level change and oracle comparisons, actual local timing, all failures and checksums. Positive-control results alone cannot authorize MASt3R or other cloud spending.
