# The initial prediction timed out before adapter setup

The local RTX 3080 probe loaded the pretrained model and reached the original depth head on five 518 × 392 images. Two nonblocking Python stack samples, about four minutes apart, both found the worker at the exponential depth activation during initial inference. The 480-second supervisor limit expired before the initial heads were captured. The worker never installed the cached weight operands and recorded zero adaptation losses and zero gradients. The stack identifies the Python call where execution waited. CUDA kernels execute asynchronously, so these samples cannot attribute the delay to the exponential itself. The successful two-update CPU comparison therefore remains the direct evidence for the cached operands. This run provides no GPU peak-memory, speed or accuracy comparison for that change. A separate probe runs initial inference with the image encoder, transformer blocks and prediction heads on the device in sequence. It retains the same inputs, arithmetic, eight planned optimizer updates and original starting-state checks. Cloud compute cost was **$0**.
