# Re-render the predicted surface after a camera update

Use only the original five predicted views per scene. For each original joint-model depth image, lift the existing grid into its world-space triangle mesh. Split each quad on the same diagonal and omit triangles whose old axial depth range exceeds 5% of their nearest vertex depth. Render this mesh in the newly updated camera of the same view using perspective-correct reciprocal-depth interpolation and a nearest-surface z buffer. On uncovered pixels retain that camera's previous predicted depth. No scene reference, reference pose, test depth or cross-view points enter inference. The existing known intrinsics and camera update determine the rays. Test identity, subpixel translation, a slanted plane and nearest-surface occlusion before scoring.

The primary arm uses the earlier fixed half-weight pose prior. Compare to fixed depth and the same prior's tangent-plane correction; evaluate full-prior and adaptive-prior re-rendering as secondary arms. Seal all maps before evaluating both canonical references. Report corresponding depth and normal errors with the registered masks and matched cameras, as well as coverage, both directional distances and original advancement criteria. This experiment tests whether transporting a connected surface can reduce the normal error introduced by independent tangent-plane intersections.
