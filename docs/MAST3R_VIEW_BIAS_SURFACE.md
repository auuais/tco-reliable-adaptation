# Does a training-side depth bias improve the reconstructed surface?

November 17, 2026. The two-direction shape screen failed. Its prespecified one-coefficient calibration control improved sparse MAE in all six scene/direction cases. This separate, exploratory follow-up tests that specific observation on dense geometry. Coefficients come from the training neighbor alone. All three scenes have been inspected in earlier research. Further evidence for generalization will require new scenes.

Use the six existing centered-grid, clean-pose, single-neighbor D alignments. Hold cameras, intrinsics, correspondence graph, checkpoint, input packet and model outputs fixed. For each fold compare the native reconstruction, the already sealed additive per-view bias, and a matched one-parameter scale control. Set scale to the median ratio of measured axial depth to native metric depth at positive training sites, clipped to [0.95,1.05]. Convert the additive correction in meters to model units with the fold's training-only gauge. Apply changes along each camera ray. Require all three output fields to be finite and record any nonpositive samples. Seal all 18 maps before opening reference data. This tests calibration applied to existing output, with USD 0 additional rental.

Score accuracy and completeness with the established similarity/ICP surface evaluator under both registered RGB and released geometry (36 associations). Normalize each distance to the native uncorrected distance in its own fold and reference, then average components and scenes equally for each source direction. Separately measure *metric axial MAE before ICP* on the registered RGB target depth in the common valid mask, using the parent reference-builder camera convention and the same training-only metric gauge. Report all directions, components and scenes separately.

For a future resource recommendation require at least 5% lower registered surface score than the stronger aggregate native/scale control in both directions, no scene regression, components at most 2% worse, and no released-reference aggregate regression. Report the secondary metric depth results independently. A positive depth-only finding can motivate a depth-calibration study. It cannot establish improved 3D reconstruction. The original partner-shape decision remains final.
