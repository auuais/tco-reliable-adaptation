# Full-size staged initialization and eight adaptation updates on the RTX 3080

On the five Heads images, the original TCO camera, depth and rendering objectives completed eight updates. All 384 adapter tensors had finite gradients at every update. The initial model predictions, initial adapter tensors, random-number state, input data, supplied priors and first total loss matched the original completed Heads control. Later losses differed between executions. [Observed losses, gradients and run checks](evidence.json)

Initial inference ran the original image encoder, transformer blocks and prediction heads in sequence on CUDA, moving inactive modules to host memory. After adapter initialization, caching BF16 operands for 192 frozen projections reduced live allocated CUDA memory by **1,208,844,288 bytes (1.126 GiB)** at the installation boundary. The run peaked at **6.71 GiB allocated** and **8.25 GiB reserved** during inference and adaptation, which took **28.76 seconds** after loading. These are measurements from one eight-update run. The original completed control used 40 updates, so its wall time is a different workload. Cloud compute cost was **$0**.
