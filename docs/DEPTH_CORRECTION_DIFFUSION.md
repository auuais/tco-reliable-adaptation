# Edge-aware diffusion of depth corrections

Use the existing 15 development targets and their leave-one-scene-out axial weights. Diffuse the resulting log-depth correction over four-connected pixels, allowing support to spread. Each adjacent pair exchanges 0.2 times its correction difference times exp(-0.5*(difference in original log depth/0.02)^2) per iteration. Apply 64 simultaneous iterations without wrapping or exchanging across frames. The symmetric update conserves the frame mean, bounds corrections by the original range, and preferentially smooths variations on continuous surfaces. Parameters are engineering choices fixed before scoring. No reference inputs enter inference.

Seal one reconstructed map per scene. Score both original reference conventions with the canonical surface evaluator, comparing against direct focal, the unsmoothed weighted correction and the same per-frame constant correction. Report the original 5% advancement gate against the complete comparator panel, scene results and component safety. The earlier shuffled control stays in the panel. An increase in normal consistency alone cannot qualify the method. This is a development experiment with three reused scenes.
