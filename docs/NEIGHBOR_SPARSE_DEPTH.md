# Neighboring sparse-depth calibration

Use the existing fifteen development targets and their fixed direct-focal VGGT predictions. At offsets of minus and plus four frames take the center ray of each cell in an eight by eight grid on each native registered depth image. Use the public camera trajectory and the existing depth-to-RGB extrinsic. Project positive valid samples up to ten meters into the zoomed target, round to pixels and keep the nearest projected sample at a collision. Target depth is restricted to the separate scoring action.

Estimate one metric gauge per scene as the median measured-to-predicted log depth ratio. Compare three updates using identical measurements. The first applies a per-view median log correction after scene gauge removal. The second interpolates local log corrections using eight nearest samples, Gaussian pixel bandwidth 48, and one unit of weight on the per-view median. The candidate adds a Gaussian predicted log-depth difference weight with bandwidth 0.08 to the same interpolation. Limit all sample log corrections to ±0.15. Keep predicted cameras fixed.

Seal all three outputs before opening evaluation geometry. Carry forward all historical controls, both references, and the existing five-part dense reconstruction threshold. A favorable development result requires repeat testing on a different sampling grid before spending on transfer. This sensor-assisted pilot uses registered public depth and supplied trajectories. It tests postprocessing of frozen predictions. It does not establish performance using measured IMU poses or learned sparse-depth adaptation.
