# Fresh-image focal repair under pose uncertainty

The first focal test measured whether RGB correspondences could distinguish wrong metadata from a consistent image zoom. The follow-up uses the five original frames at offsets 0, 200, 400, 600 and 800 in each of the same three 7-Scenes development sequences. None of these 15 images appeared in the nine-window focal experiment. Prior TCO studies have used these sequences and frames. [Previous test](../results/focal_metadata_control/RESULTS.md)

### Inputs and interventions

Use the frozen 518 × 392 public RGB inputs. Define the common image as a 1.12× center crop about the registered principal point. Modify one of five cameras by another factor of 1.12 or its reciprocal. Resample directly from the original raster once. Thus the widest view is the native image and the narrowest is a 1.2544× crop. Apply the same transform to the true camera intrinsics. For each of the three scenes there are 11 distinct image batches. Re-extract DISK features and recompute LightGlue matches and connected-track folds for each batch. Run the original frozen VGGT aggregator and camera head separately for each batch on the local CPU in FP32. The weights, raster, camera-head refinement and view ordering are fixed. Record the exact encodings and input fingerprints.

Compare four metadata states per scene, selected view and scale. (1) Baseline images with a spurious focal outlier. (2) Zoomed images with a correct focal outlier. These two have identical supplied intrinsics. (3) Zoomed images with the real focal change missing from metadata. (4) Baseline images with the correct uniform focal metadata. These last two also have identical supplied intrinsics. Count the common fourth case once per scene and pose realization when reporting absolute counts. The hidden-change cases measure a structural limitation of using an outlier to trigger a proposal.

Use three pose conditions. Keep the first camera fixed. Perturb the other four independently about their camera centers, with no perturbation, 1° plus 2% of the sequence's camera-center diameter, or 3° plus 6%. Use the same deterministic per-camera directions at both severities, with two direction seeds (137 and 941) at each nonzero level. Apply a given noisy pose rig identically to both members of every pair. This gives five pose realizations per image configuration. Load no measured depth or external SfM labels for this study.

### Decision and endpoints

Use the frozen two-fold focal rule, threshold 0.25 pixels. Compare no editing, always using the neighbor consensus, and the one-fold rule. Also evaluate the pretrained VGGT alternative that chooses the closer of the supplied and median focal lengths in mean absolute log focal across both axes. All methods keep the supplied poses. Equal focal inputs produce an abstention for every method. No ground-truth poses, depth, case labels or gradients enter any decision.

Compare the original TCO external pose and intrinsics loss gradients at the actual image-conditioned VGGT camera output. For each candidate, compare its field-of-view gradient with the gradient from correct focal metadata and the same supplied poses. Normalize the error by the norm of the ideal field-of-view gradient, floored at 1e-6. Report the absolute gradient errors and baseline saturation counts as well. Compare the entire 45-dimensional gradient with the one obtained using true poses and true intrinsics. Record absolute log-focal error and edit rates separately. These are gradients at the head output; a dense inference or LoRA update must be tested separately.

The primary group is the two visible-outlier cases at 1° and 2% pose noise. Average equally across scenes, five perturbed views, both scale directions, both metadata cases and both direction seeds. To justify a dense development pilot, the two-fold rule must reduce mean relative focal-gradient error by at least 20% against both unconditional methods, match or beat the VGGT proximity rule, worsen no scene against the better unconditional method, and incorrectly edit at most 5% of valid zooms. Include the 3° stress test and the correctly specified and hidden-change controls irrespective of this outcome. The one-fold rule is an ablation. Report any tradeoff. This study uses local compute and releases no transfer funds.
