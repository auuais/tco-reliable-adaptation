# Checking the dense reference for a cropped RGB image

We tested the evaluation geometry on the previously sealed Heads, Chess and Fire windows at offset 50. Five views, three crop factors and two camera conventions yielded 90 reference configurations. At identity zoom, the reconstructed reference agreed with the existing dense evaluation on valid pixels within **2.23 × 10⁻⁷ m**. Across 14,787,066 valid pixels away from nearest-neighbor ties, the independently sampled axial depths agreed within **8.89 × 10⁻¹⁶ m**, and the lifted points reprojected to their target pixel within **4.55 × 10⁻¹³ pixels**. These checks validate the evaluator. They do not estimate reconstruction accuracy. [All 90 checks](reference_checks.json)

For a crop about the registered RGB principal point with image affine matrix A, the new reference matrix is A times the original K. This also shifts the principal point when the released camera convention uses a slightly different center. Each output pixel takes its nearest source axial-depth sample and is lifted along its own calibrated ray. Out-of-view or invalid source depth produces an invalid output.

Nearest-neighbor sampling uses round-to-even in this implementation. OpenCV's affine warp can choose the other neighbor near a half-pixel. The independent check reports 248 mask differences, all within the declared 0.003-pixel band around a rounding boundary. Those sites remain in the generated evaluation masks wherever their selected source depth is valid.
