# MASt3R joint-prior alignment implementation

Keep the released MASt3R checkpoint and cached descriptor matches fixed. Add optional camera and sparse-depth residuals inside fine sparse global alignment, so the optimizer can coordinate camera, focal and depth variables. The earlier output-substitution transfer failed on Fire. This implementation tests a geometric optimization hypothesis. Learned network-weight or LoRA adaptation is a later implementation and is not established by this stage.

The first integration check compiles the pinned upstream optimizer with a disabled additive-loss hook and reruns ordinary alignment on Heads. The hook must preserve the loss expression and parameter updates when disabled. Compare the resulting camera matrices, intrinsics and dense depth with the previously captured standard run and report numerical differences. No target depth is used. Keep upstream source on disk unchanged, record its normalized-text SHA-256, and restore the original module function after the scoped call.

For subsequent fine-stage tests, the intended priors use the existing centered and shifted neighboring-frame sparse samples and supplied trajectories from the original three development scenes. Use the same native pixel-center resize transform as the model inputs and document sample quantization to the canonical depth grid. Match the coordinate gauge using only sparse ranges and relative cameras. Compare standard alignment, depth-only, pose-only and joint priors before selecting an adaptive weighting rule. Fix all group weights and schedules before scoring the corresponding runs. Coarse alignment initially remains the released objective.

Validate finite losses, gradients and dense outputs locally, profile memory and runtime, and preserve all failed attempts. Prepare inference and predictions before any dense reference is opened. Rental spending for this implementation is zero. The existing USD 25 allocation remains subject to its resource decision.

The first prior integration probe uses weights 0.01 for sparse depth and 0.01 for the sum of relative rotation and translation terms, with a one-step fine-stage execution check. Use Huber residuals with transition 1 after normalization: depth residual divided by 0.02 times median measured depth, relative translation divided by the same metric unit, and relative rotation-matrix entries divided by 0.02. Establish a fixed metric scale at the first fine iteration from the median positive sparse measured/predicted range ratio. All groups use that same gauge, including the pose-loss-only ablation. Coarse alignment has zero prior weight.

Relative poses are anchored to view zero and are invariant to a global camera-frame change. Native sparse samples are rounded using the pixel-center affine from 518 by 392 into the canonical image grid, with nearest measured depth retained at collisions. The signed axial-depth residual preserves a gradient for negative predictions. Report retained sample counts and all objective components. These fixed choices are an integration probe and are not a tuned model or a reconstruction claim.

Record both iteration count and effective returned-update count.
