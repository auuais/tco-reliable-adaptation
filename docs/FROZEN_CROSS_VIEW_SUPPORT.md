# Cross-view support from frozen point maps

Use the five existing direct-focal maps per development scene. Use a regular four-pixel lattice on every source and query image for the diagnostic. Normalize world distances by the median predicted axial depth over all five views. For each baseline query, identify the two closest distinct other views using nearest sampled points. Freeze the query support and source maps across comparisons. Count separately the fractions with one and two other views within 0.02 median depths. Compare mean nearest-neighbor distances on two-view-supported queries to the same frozen source views for direct, axial weighted, diffused and RGB-rigid proposals. Pool queries equally within each scene. Select a whole-scene map only with at least 5% supported queries and at least a 1% gain versus direct. Otherwise retain direct. Seal choices before replaying both canonical reference scores.

Additionally test an explicit depth proposal on full-resolution query pixels. Estimate normals by centered differences of full-resolution direct-focal source coordinates, sampled at the four-pixel lattice. For each query intersect its original camera ray with the tangent planes of its two closest other views. Require both distances within the same threshold, absolute ray-normal cosine at least 0.4 for both, finite normals, and agreement of inferred displacements within 0.01 median depths. Move halfway to the average predicted intersection, limiting the signed displacement to 0.02 median depths. Freeze all source maps during this simultaneous update. Save the entire reconstructed map, count support, and evaluate against the original surface gate with both references. No reference geometry enters inference. Distinct predicted views share a network and may share errors. These reused development scenes cannot establish generalization.
